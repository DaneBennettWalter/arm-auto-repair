## Critical Issues Detail

### 1. Backend Server Not Running

**Problem:**
```bash
# Expected:
curl http://localhost:3002/api/health
# Actual:
Failed to connect to localhost port 3002
```

**Root Cause:**
- Server never started after deployment
- No pm2 config for manager-server
- tsx (TypeScript runner) not installed globally

**Fix Required:**
```bash
sudo npm install -g tsx
cd /opt/dao1/apps/manager-server
sudo pm2 start server/index.ts --name day1-api --interpreter tsx
sudo pm2 save
sudo pm2 startup
```

---

### 2. OAuth Redirect URI Mismatch

**Problem:**
User tries to log in → Google rejects with `redirect_uri_mismatch`

**Evidence:**
File: `/opt/dao1/apps/manager-server/server/routes/auth.ts`

```typescript
Line 550: const GOOGLE_REDIRECT_URI = process.env.GOOGLE_REDIRECT_URI || 'https://manager.dao1.earth/api/auth/google/callback'
```

All redirect URLs hardcoded to `manager.dao1.earth` instead of `day1.build`

**Affected Lines:**
- 550, 586, 592, 599, 602, 620, 630, 658, 661 (Google OAuth)
- 690, 710, 716, 726, 739, 747, 761, 790, 793 (X/Twitter OAuth)

**Fix Required:**
```bash
sudo sed -i 's/manager\.dao1\.earth/day1.build/g' /opt/dao1/apps/manager-server/server/routes/auth.ts
```

**Also needed:**
Add to Google OAuth Console:
- `https://day1.build/api/auth/google/callback`

---

### 3. TypeScript Runtime Missing

**Problem:**
Cannot run TypeScript files directly

```bash
node index.ts
# Error: Cannot find module '.../lib/db.js'
```

**Why:**
- TypeScript import statements resolve to `.js` at runtime
- Node.js needs a TS loader (tsx, ts-node, or compiled .js files)
- No build step configured

**Fix:**
```bash
sudo npm install -g tsx
```

---

### 4. No PM2 Process Management

**Problem:**
manager-server not configured in PM2

```bash
pm2 list
# Shows: only legacy api on port 3001
# Missing: day1-api (port 3002)
```

**Impact:**
- Server won't auto-restart on crash
- Won't survive reboot
- No logs, no monitoring

**Fix:**
```bash
pm2 start server/index.ts --name day1-api --interpreter tsx
pm2 start server/index.ts --name day1-staging --interpreter tsx -- --port 3003
pm2 save
```
